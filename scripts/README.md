# Salmonella Downstream Analysis in R

This repository contains R scripts developed for the analysis and visualization of Salmonella enterica genomic and epidemiological data from beef production environments.

## Scripts

### Salmonella_serovar_heatmap.R
Generates a heatmap showing temporal distributions of Salmonella serovars across years.

### amr_prevalence_by_serovar.R
Calculates antimicrobial resistance gene prevalence across Salmonella serovars and produces comparative visualizations.

### merge_amr_metadata.R
Merges AMRFinderPlus results with isolate metadata for downstream analysis.

### n50_qc_visualizations.R
Generates assembly quality-control metrics including N50, contig counts, assembly length, and coverage summaries.
